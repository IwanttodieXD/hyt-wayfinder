--------------------------------------------------------------------------------
FEATURES
--------------------------------------------------------------------------------

1. 3D BUILDING TOUR
   - First-person exploration of HYT Global Institute (5 floors)
   - Desktop controls (WASD + mouse) and mobile touch controls
   - Interactive floor navigation with real-time position tracking

2. STUDENT QR CLOCK-IN SYSTEM ★ NEW ★
   - Dual-view interface: Student Mobile App + Lobby Kiosk Station
   - Animated QR scanner with laser scan effects
   - Real-time clock-in/out tracking with timestamps
   - Interactive 3D wayfinding with animated route visualization
   - Guest check-in simulation with ID scanning

STATE MANAGEMENT  (store/)
--------------------------------------------------------------------------------

store/clockInStore.ts  ★ NEW ★
  PURPOSE : Zustand global state for clock-in system.
  STATE :
    - viewMode: 'mobile' | 'kiosk'
    - student: { id, name, destination, building, room }
    - clockInTime: Date | null
    - status: 'not-clocked-in' | 'clocked-in' | 'viewing-route'
    - activeStudents: number (default: 47)
    - dailyVisits: number (default: 203)
    - isRouteAnimating: boolean
    - currentWaypoint: number (0-5)
  ACTIONS :
    - setViewMode(), clockIn(), clockOut(), startRouteView()
    - setRouteAnimating(), setCurrentWaypoint(), resetRoute()
  WHAT TO EDIT :
    - Student profile (Alex Rivera → your student name/ID)
    - Initial metrics (activeStudents, dailyVisits)
    - QR expiry logic (currently manual)

QUICK REFERENCE — MOST COMMON EDITS
--------------------------------------------------------------------------------

BUILDING TOUR:
  Change movement speed          →  hooks/useFirstPersonControls.ts  (speed = 10.0)
  Change building size/floors    →  components/Building.tsx
  Change camera start position   →  components/Scene.tsx  (position: [0, 1.6, 10])

CLOCK-IN SYSTEM:
  Change student profile         →  store/clockInStore.ts  (student object)
  Change destination/room        →  store/clockInStore.ts + waypoints array
  Adjust waypoint positions      →  components/RouteVisualization.tsx  (waypoints)
  Modify QR code value           →  components/KioskStationView.tsx  (QRCode value)
  Change animation speed         →  RouteVisualization.tsx  (setTimeout 2000ms)
  Update kiosk metrics           →  store/clockInStore.ts  (activeStudents, dailyVisits)
  Customize scanner colors       →  QRScanner.tsx  (border-cyan-400, bg-cyan-500)

TO RUN:
  npm install react-qr-code      →  Install QR code dependency
  npm run dev                    →  Start dev server
  Visit: http://localhost:3000/clock-in
