# ☕ Quick Start: 3D Barista Cafe

## 🚀 5-Minute Setup

### Step 1: Start the Server
```bash
cd hyt-wayfinder
npm run dev
```

### Step 2: Open Browser
Navigate to: `http://localhost:3000`

### Step 3: Find the Cafe
1. Click **"☕ Barista Game"** button on homepage
2. Read the instructions
3. Click **"🏢 Enter 3D Building Tour"**

### Step 4: Navigate
- Press `W` `A` `S` `D` to move
- Move mouse to look around
- Click anywhere to lock pointer

### Step 5: Interact
- Find the **golden "TESDA BARISTA"** sign on ground floor (left side)
- Walk up to the equipment
- **Click** on:
  - 🟢 **Coffee Grinder** (green when active)
  - 🔴 **Espresso Machine** (orange glow when active)
  - 🔴 **Milk Steamer** (red with steam when active)

## 🗺️ Finding the Cafe

### Visual Landmarks:
1. **Spawn Location**: You start in the building
2. **Stay on Ground Floor**: Don't go upstairs
3. **Look Left (West)**: The cafe is on the left side
4. **Golden Sign**: You'll see a glowing golden sign that says:
   ```
   TESDA BARISTA
   Training Cafe
   ```
5. **Counter**: Brown wooden counter with equipment on top

### If You're Lost:
- The cafe is at building coordinates: `(-12, 0.5, -8)`
- Look for the brightest golden glow
- It's in the first room on the left wing

## ✨ What Happens When You Click

### Coffee Grinder
```
Click! → Hopper spins → Green glow → "GRINDING..." → Auto stops
```

### Espresso Machine
```
Click! → Buttons light up → Orange glow → "BREWING..." → Cup fills → Auto stops
```

### Milk Steamer
```
Click! → Steam rises → Red glow → "STEAMING..." → Particles float → Auto stops
```

**Duration**: Each action lasts ~2 seconds

## 🐛 Troubleshooting

### "I can't see the cafe"
- Make sure you're on the **ground floor** (first floor)
- Turn left and walk forward
- Look for the **golden glowing sign**

### "Equipment won't click"
- Get closer to the equipment
- Make sure your pointer is locked (click once)
- Aim directly at the equipment piece

### "Movement feels stuck"
- Press `ESC` to unlock pointer
- Click again to re-lock
- Make sure you're using `WASD` keys

### "Performance is slow"
- Close other browser tabs
- Use Chrome or Edge browser
- Reduce window size

---

## 📱 Mobile Users

The 3D experience works on mobile but:
- Use touch to look around
- Touch and drag to move
- Tap equipment to interact
- Performance may be reduced

**Best experience**: Desktop with mouse and keyboard
